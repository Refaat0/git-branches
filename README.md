## Installation && Testing
Clone the repository to your local machine:
```
refaat@xubuntu:~$ git clone https://github.com/Refaat0/git-branches
```

Run the tests:
```
refaat@xubuntu:~/python-playground$ python3 -m unittest tests/test_lib.py
```
